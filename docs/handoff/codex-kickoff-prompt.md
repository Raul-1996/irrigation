ЖЁСТКИЕ ОГРАНИЧЕНИЯ:
- Python 3.11 минимум. Фичи 3.12+ ЗАПРЕЩЕНЫ: tomllib, asyncio.TaskGroup, except*,
  generic type syntax (def f[T]). PEP 604 (X | None) — разрешён.
- Прод на реальном железе. Ошибка в логике полива = залитый или засохший участок,

- Один процесс с фоновыми тредами: блокирующий вызов под локом = дедлок всего

- Параллельный прогон тестов (-n) флейкает на логин-тестах. Решение всегда принимать
  по СЕРИЙНОМУ прогону.
- e2e и mqtt_real деселектятся по умолчанию (нужны WB_E2E_URL, WB_E2E_PASSWORD,
